# 📝 Task Tracker - Frontend

This is the frontend application for the Task Tracker system. It provides a modern, responsive user interface to manage tasks and categories, built using the latest Next.js features.

## 🚀 Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Backend:** FastAPI + PostgreSQL (Separate Repository)

## ⚙️ Prerequisites

Before you begin, ensure you have the following installed on your local machine:
* [Node.js](https://nodejs.org/) (v18 or higher)
* npm (comes with Node.js)
* The [Task Tracker Backend](https://github.com/Thejan2006/task-tracker-backend) should be running locally.
